## 3. 다시 해 보는 방법

- 직접: `영화_A_초안.html`을 더블클릭해 브라우저로 열고 위 표의 "해 본 행동"을 순서대로 따라 합니다.
- 자동: Node.js와 Playwright가 있으면 저장소 폴더에서 아래 명령으로 같은 검증을 다시 돌릴 수 있습니다.

  ```
  node 미션1_실행검증/자동검증_스크립트.js 영화_A_초안.html 미션1_실행검증/영화_A
  ```
