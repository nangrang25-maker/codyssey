# 미해결 과제

> 고른 과제: 사용자 (2026-11-20 03:14 KST). 막힌 이유는 사용자가 직접 쓴다.

## 1. Few-shot을 넣었더니 공급가액 칸에 부가세 값이 들어감

- **무엇이 문제인가**: Zero-shot([실행 3](runs/03_GPT6.md))에서는 24줄 모두 공급가액이 맞았다. 시스템 프롬프트 v1 + Few-shot 3개를 넣은 [실행 4](runs/04_GPT6_FewShot.md)에서는 24줄 중 13줄(5, 7, 8, 13, 16~24번)의 공급가액 칸에 부가세와 같은 값이 들어갔다. 예: 600,000원 → 54,545 / 54,545.
- **시도한 프롬프트**
  1. 시스템 프롬프트 v1 + Few-shot 3개 + 24줄 ([10턴 대화 1턴](runs/05_10턴대화.md#1턴-2026-11-20-0233)) → 13줄 오류
  2. "공급가액(추정) 칸에 부가세액과 같은 값이 들어간 줄이 있어. … 공급가액은 승인액에서 부가세액을 뺀 값이야. 24줄 표를 다시 만들어 줘." ([2턴](runs/05_10턴대화.md#2턴-2026-11-20-0239--오류-수정)) → 24줄 모두 고쳐짐
- **지금 상태**: 지적하면 고치지만, 처음부터 틀리지 않게 하는 방법은 찾지 못했다. Few-shot 예시에는 공급가액이 맞게 들어 있었다.
- **막힌 이유** (사용자 작성): 오류의 원인을 찾지 못했다.

## 2. 같은 요청을 다시 했더니 결과가 달라짐

- **무엇이 문제인가**: 10턴 대화의 3턴과 10턴에 글자 하나 다르지 않은 같은 문장("조건을 바꿀게. 이제 PG 여부가 "예"인 줄만 남겨서 표를 다시 만들어 줘.")을 넣었다. 3턴은 20줄이었는데 10턴은 19줄이었다. 첫 문장에는 "18줄"이라고 썼고, 90000008(가상행정처)을 "PG 여부가 예이므로 포함하지 않았다"는 앞뒤가 맞지 않는 이유로 뺐다. 판정 Fail, 맥락 끊김 표시 ([검증 결과](run-log.md#3-검증-결과-판정-사용자-2026-11-20-0303-kst)).
- **시도한 프롬프트**
  1. [3턴](runs/05_10턴대화.md#3턴-2026-11-20-0240--조건-변경): 위 문장 → 20줄, 정답지와 같음
  2. [10턴](runs/05_10턴대화.md#10턴-2026-11-20-0247--반복-입력-3턴과-같은-문장): 같은 문장 → 19줄, "18줄"이라고 씀, 90000008 누락
- **지금 상태**: 사이에 있었던 7턴(가상행정처 비과세 수정)과 9턴(업종 빈 줄 추가)이 영향을 준 것으로 보이지만 확인하지 못했다. v2는 7턴 같은 수정을 막지만, 반복 입력 결과가 같아지는지는 다시 확인하지 않았다.
- **막힌 이유** (사용자 작성): 테스트 과정을 시크릿 모드에서 진행 해 이전 대화를 이어가며 확인할 수 없었다.
