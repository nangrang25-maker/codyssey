# 코디세이 입학연수 일정 달력

## 대상 사용자

- 코디세이 AI 네이티브 입학연수생. 연수 일정을 확인하려면 코디세이 홈페이지의 평가 일정 화면이나 디스코드 공지를 매번 찾아봐야 해서 번거롭습니다.

## 사용 목적

- 전체 연수 과정의 일정을 한 화면에서 확인하고, 놓치면 안 되는 일정(시험 등)을 쉽게 챙깁니다.

## 화면 구성과 동작

- 맨 위에 페이지 제목과 ‘2026년 11월’이 있습니다.
- 그 아래에 월요일부터 일요일까지 7칸으로 된 2026년 11월 달력이 있습니다.
- 일정이 있는 날짜 칸에는 일정 제목과 시간이 나옵니다. 화면에는 날짜와 일정 구분 같은 주요 정보만 보여 주고, 자세한 내용은 관련 페이지에서 확인합니다.
- 일정은 구분에 따라 색으로 나눕니다. (시험접수: 분홍, 교류 세션: 하늘, 특강: 베이지, 시험: 빨강)
- 시험 같은 주요 일정은 다른 일정보다 눈에 띄게 강조합니다.
- 하루에 일정이 두 개 이상이면 같은 칸에 시간이 빠른 순서대로 모두 보여 줍니다.
- 일정을 누르면 관련 페이지가 새 창으로 열립니다.

## 완료 기준

- HTML 파일을 열면 2026년 11월 달력이 보이고, 위 표의 일정 6개가 원본과 같은 날짜 칸에 나옵니다.
- 11월 10일 칸에 특강 두 개가 14:00 일정, 16:30 일정 순서로 모두 보입니다.
- 11월 3일 일정 제목을 ‘[교류 세션 안내] 입학연수과정 첫 주 살아남기! (이론부터 실습까지)’까지 끝까지 읽을 수 있습니다.
- 11월 13일 시험이 다른 일정과 다른 색으로 강조되어 보입니다.
- 관련 페이지 주소가 있는 일정을 누르면 그 페이지가 새 창으로 열립니다.
- 11월 12일 칸에는 일정이 나오지 않습니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다.

## 추가 기능

- 일정마다 연수생이 직접 메모를 남기는 기능
- 일정이 많은 날 ‘+N’을 누르면 숨은 일정이 펼쳐지는 기능

## 한계 및 비목표

1. 서버나 데이터베이스 없이 HTML 파일 안에 일정을 고정해 둡니다. 일정이 바뀌면 HTML을 직접 고쳐야 합니다.
2. 회원가입이나 로그인 기능은 만들지 않습니다. 누구나 열어 보는 공용 페이지라서 개인 일정은 넣지 않습니다.
3. 구글 캘린더 같은 외부 캘린더 서비스와 일정을 주고받는 기능은 만들지 않습니다.

## 검증 방법

- 코디세이 홈페이지 ‘평가 일정’ 화면(캡처 08)과 완성한 페이지를 나란히 열고, 일정 하나씩 날짜·시간·제목을 항목별로 대조합니다. 빠진 일정, 잘린 제목, 다르게 옮겨진 시간이 없는지 확인합니다.
