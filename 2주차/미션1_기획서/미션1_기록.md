## 4. AI 결과 중 의도와 달라서 직접 고친 부분

Gemini 대화 안에서 고친 부분:

| AI가 쓴 내용 | 문제 | 고친 내용 |
| --- | --- | --- |
| 일정 데이터 예시: 2024-03 날짜, `example.com` 링크 | 실제 연수 일정이 아님 | 코디세이 ‘평가 일정’ 화면을 출처로 정하고 실제 일정 6개를 넣음 |
| 11월 10일 시간 `14:00 15:00 / 16:30 17:30`이 한 칸에 섞임 | 원본은 특강 두 개 | 14:00~15:00, 16:30~17:30 두 일정으로 나눔 |
| 11월 3일 제목 `[교류 세션 안내] 입...` | 원본 화면에서 제목이 잘린 채로 옮김 | 전체 제목 ‘[교류 세션 안내] 입학연수과정 첫 주 살아남기! (이론부터 실습까지)’를 직접 알려 줌 |
| 11월 12일 ‘평가참여’와 ‘+9’ 포함 | 내 개인 일정이라 공용 페이지에 맞지 않음 | 12일 일정은 모두 뺌 |

| 기획서 형식: 프로젝트 개요, 데이터 정의 등 | 미션 양식 순서와 다름 | 기획서 양식 순서로 다시 정리 |

- Gemini와의 질의응답, 내가 고친 내용을 바탕으로 기획서 양식에 옮겨 [기획서.md](기획서.md)를 만들었습니다. 양식 옮기기와 문장 정리는 Claude의 도움을 받았고, 내용은 위 대화에서 내가 답하고 정한 것만 넣었습니다.
