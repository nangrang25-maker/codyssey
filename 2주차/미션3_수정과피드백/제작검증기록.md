### 수정 기록 1 (미션2 테스트 1에서 예상과 달랐던 것, 가장 먼저 수정)
- 발견한 문제:
  - 테스트 내용: 3일 교류 세션 등 일정을 눌러 본다.
  - 예상 결과: 관련 페이지 주소가 있는 일정을 누르면 그 페이지가 새 창으로 열린다. (기획서 완료 기준)
  - 실제 결과: 어떤 일정을 눌러도 아무 일도 일어나지 않는다. ([미션2 테스트 1](../미션2_두AI비교/제작검증기록.md))
- AI에게 전달한 요청 (GPT-5.5, 미션2와 같은 대화에 이어서, [캡처 01](캡처/01_수정1_GPT요청과응답.png)):
  > 3일 교류 세션 일정을 눌렀는데 아무 일도 일어나지 않아요. 기획서에는 누르면 관련 페이지가 새 창으로 열린다고 되어 있어요. 이 부분만 고쳐서 HTML 전체를 다시 주세요. 실제로 사용해보니 링크 연결은 불필요하다고 느껴서 링크 연결 기능은 삭제할게요.
  - 결정: 연수생에게 보여 줄 실제 상세 페이지가 없고, 일정 확인에는 날짜·시간·제목으로 충분해서 링크 연결 기능을 빼기로 했습니다. 기획서의 완료 기준과 필수 기능도 이에 맞게 고칩니다.
  - 받은 결과: [연수일정_v2.html](연수일정_v2.html). v1과 비교하면 일정에 마우스를 올려도 누를 수 있는 모양이 아니게 바뀌었고(`cursor: default`, 마우스 올림 효과 삭제), 위 안내 문구와 아래 검증 기준에 링크 삭제 문장이 추가되었습니다.
- 수정 후 테스트 결과 ([캡처 02 넓은 화면](캡처/02_v2_넓은화면.png), [캡처 03 좁은 화면](캡처/03_v2_좁은화면.png)):
  - 일정을 눌러도 다른 페이지로 이동하지 않고, 누를 수 있는 것처럼 보이지 않습니다. → 링크를 빼기로 한 의도대로 됨.
  - 기존 기능 재확인: 일정 6개 그대로, 10일 이른 시간순, 13일 시험 강조, 좁은 화면에서 세로 목록 모두 v1과 똑같이 작동합니다.
  - 요청하지 않은 변경: AI가 위 안내 문구에 “링크 연결 기능은 삭제했으며, 일정은 확인용으로만 표시합니다.”를, 아래 검증 기준에 13일 강조·링크 삭제 문장을 새로 넣었습니다. 연수생에게 필요 없는 설명이 오히려 늘어나서 수정 2, 3에서 함께 정리합니다.
- 수정 이유: 연수생이 일정의 자세한 내용을 보려고 눌러도 아무 반응이 없어, 결국 코디세이 홈페이지나 디스코드를 다시 찾아봐야 한다.

### 수정 기록 2 (원래 계획한 문제 2, 3을 한 번에 요청함)
- 발견한 문제:
  - 테스트 내용: v2를 열고 달력 위 안내 상자와 달력 아래 상자를 읽는다. ([캡처 02](캡처/02_v2_넓은화면.png))
  - 예상 결과: 연수생이 일정을 보는 데 필요한 내용만 보인다.
  - 실제 결과: 위 상자에 “링크 연결 기능은 삭제했으며, 일정은 확인용으로만 표시합니다. 11월 12일 개인 일정은 포함하지 않았습니다.”가, 아래 상자에 ‘검증 기준’ 6줄과 ‘사용한 AI 서비스와 모델 이름: ChatGPT’가 보인다. 수정 1 때 요청하지 않은 문장도 늘어났다.
- AI에게 전달한 요청 (GPT-5.5, 같은 대화, [캡처 04](캡처/04_수정2_GPT요청과응답.png)):
  > 검토결과 제가 요청하지 않은 추가 문구를 넣은 점을 확인했습니다. 달력 상하단의 설명은 섹션 자체를 삭제합니다. 이 캘린더를 이용하는데에 불필요한 기능입니다. 다른 부분은 수정하지 않고 전체 html로 제공합니다.
  - 받은 결과: [연수일정_v3.html](연수일정_v3.html). v2와 비교하면 위 안내 상자(`notice`)와 아래 상자(`footer`)의 HTML과 스타일만 지워졌고, 달력·일정·색상 안내는 그대로입니다.
  - 처음엔 위 문구(문제 2)와 아래 문구(문제 3)를 따로 고치려 했지만, 둘 다 “페이지에 필요 없는 설명”이라는 같은 문제라서 한 요청으로 묶었습니다. 그래서 세 번째 수정은 사용자 테스트 피드백에서 가져옵니다.
- 수정 후 테스트 결과 ([캡처 05 넓은 화면](캡처/05_v3_넓은화면.png), [캡처 06 좁은 화면](캡처/06_v3_좁은화면.png)):
  - 달력 위 안내 상자와 달력 아래 검증 기준·모델 이름 상자가 모두 사라지고, 제목·‘2026년 11월’·색상 안내 바로 아래에 달력이 나옵니다. → 의도대로 됨.
  - 기존 기능 재확인: 일정 6개 그대로, 10일 이른 시간순, 13일 시험 빨간 테두리 강조, 일정을 눌러도 이동하지 않음, 좁은 화면에서 세로 목록과 3일 긴 제목이 잘리지 않음 모두 v2와 똑같이 작동합니다.
  - 이번에는 요청하지 않은 문장이 추가되지 않았습니다.
- 수정 이유: 만든 사람의 작업 메모와 검증용 문장이 연수생에게 그대로 보여 페이지가 완성되지 않은 것처럼 보이고, 일정을 찾기 전에 읽어야 할 글만 늘어난다.
