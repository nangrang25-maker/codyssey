# 코디세이 입학연수 일정 달력

> 이 기획서의 구성
> - 기본 항목 5개: ① 대상 사용자 ② 사용 목적 ③ 화면 구성과 동작 ④ 필요한 자료 ⑤ 완료 기준
> - 필수 기능 / 추가 기능
> - 한계 3개 / 비목표 3개
> - 검증 방법 1개
> - 사용한 AI 서비스와 모델 이름

## ① 대상 사용자

- 코디세이 AI 네이티브 입학연수생. 연수 일정을 확인하려면 코디세이 홈페이지의 평가 일정 화면이나 디스코드 공지를 매번 찾아봐야 해서 번거롭습니다.

## ② 사용 목적

- 전체 연수 과정의 일정을 한 화면에서 확인하고, 놓치면 안 되는 일정(시험 등)을 쉽게 챙깁니다.

## ③ 화면 구성과 동작

- 맨 위에 페이지 제목과 ‘2026년 11월’이 있습니다.
- 그 아래에 월요일부터 일요일까지 7칸으로 된 2026년 11월 달력이 있습니다.
- 일정이 있는 날짜 칸에는 일정 제목과 시간이 나옵니다. 화면에는 날짜·시간·제목과 일정 구분 같은 주요 정보만 보여 줍니다.
- 일정은 구분에 따라 색으로 나눕니다. (시험접수: 분홍, 교류 세션: 하늘, 특강: 베이지, 시험: 빨강)
- 시험 같은 주요 일정은 다른 일정보다 눈에 띄게 강조합니다.
- 하루에 일정이 두 개 이상이면 같은 칸에 시간이 빠른 순서대로 모두 보여 줍니다.
- 일정은 확인용으로만 보여 주며, 눌러도 다른 페이지로 이동하지 않습니다.
- 달력 위아래에 만든 사람용 설명(개인 일정 제외 안내, 검증 기준, 사용한 모델 이름)은 넣지 않습니다.
- 1920 x 1080 화면에서 스크롤하지 않아도 11월 1일부터 30일까지 달력 전체가 한 화면에 보입니다.
- 좁은 화면(휴대폰 너비)에서는 날짜별 세로 목록으로 바뀝니다.

## ⑤ 완료 기준

- HTML 파일을 열면 2026년 11월 달력이 보이고, 위 표의 일정 6개가 원본과 같은 날짜 칸에 나옵니다.
- 11월 10일 칸에 특강 두 개가 14:00 일정, 16:30 일정 순서로 모두 보입니다.
- 11월 3일 일정 제목을 ‘[교류 세션 안내] 입학연수과정 첫 주 살아남기! (이론부터 실습까지)’까지 끝까지 읽을 수 있습니다.
- 11월 13일 시험이 다른 일정과 다른 색으로 강조되어 보입니다.
- 일정을 눌러도 다른 페이지로 이동하지 않습니다.
- 달력 위아래에 만든 사람용 설명 상자가 없습니다.
- 1920 x 1080 화면에서 스크롤하지 않고 11월 30일까지 볼 수 있습니다.
- 11월 12일 칸에는 일정이 나오지 않습니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다.

## 필수 기능

이번 HTML에서 반드시 구현합니다.

1. 2026년 11월 달력 표시: 월~일 7칸 달력에 ‘필요한 자료’의 일정 6개를 날짜 칸에 넣어 보여 줍니다.
2. 일정 강조: 일정 구분마다 색을 다르게 하고, 시험처럼 주요 일정은 눈에 띄게 강조합니다.
3. 같은 날 여러 일정 표시: 하루에 일정이 두 개 이상이면 같은 칸에 시간순으로 모두 보여 줍니다.
4. 한 화면에 한 달 보기: 1920 x 1080 화면에서 스크롤 없이 11월 1일부터 30일까지 모두 보이고, 좁은 화면에서는 날짜별 세로 목록으로 바뀝니다.

## 추가 기능

이후에 구현할 기능입니다. 이번 HTML에는 넣지 않습니다.

- 일정마다 연수생이 직접 메모를 남기는 기능
- 일정을 누르면 코디세이 공지 등 관련 페이지가 열리는 기능 (실제 연결할 상세 페이지가 생기면 추가)
- 일정이 많은 날 ‘+N’을 누르면 숨은 일정이 펼쳐지는 기능

## 한계 및 비목표

### 한계 (이 페이지가 못 하는 것)

1. 2026년 11월 코디세이 ‘평가 일정’ 화면에 나온 일정 6개만 보여 줍니다. 다른 달이나 다른 공지의 일정은 나오지 않습니다.
2. 일정이 HTML 파일 안에 고정되어 있어서, 공지 일정이 바뀌어도 페이지에 저절로 반영되지 않습니다. 바뀌면 HTML을 직접 고쳐야 합니다.
3. 연수생 개인의 일정(예: 동료평가 참여 시간)은 보여 주지 않습니다.

### 비목표 (이번 구현에서 일부러 빼는 것)

1. 서버나 데이터베이스는 만들지 않습니다.
2. 회원가입이나 로그인 기능은 만들지 않습니다. 누구나 열어 보는 공용 페이지입니다.
3. 구글 캘린더 같은 외부 캘린더 서비스와 일정을 주고받는 기능은 만들지 않습니다.

## 검증 방법

비교 대상: 코디세이 홈페이지 ‘평가 일정’ 화면, 2026년 11월 ([캡처 08](캡처/08_원본_코디세이평가일정.png))

1. 원본 평가 일정 화면과 완성한 HTML을 나란히 엽니다.
2. 원본에서 일정을 하나씩 골라, HTML의 같은 날짜 칸에 그 일정이 있는지 확인합니다.
3. 일정마다 날짜·시간·제목을 원본과 글자 단위로 대조하고, 표에 ‘일치/불일치’를 적습니다.
4. 원본에 있는데 HTML에 없는 일정, HTML에만 있는 일정이 있는지 셉니다. (12일 개인 일정은 빼기로 했으므로 HTML에 없어야 맞습니다.)
5. 불일치가 하나라도 있으면 어느 일정의 어느 항목이 다른지 기록합니다.
