# codyssey
github와 codyssey를 연동하기 위해 만들어진 repository입니다. 

## 폴더 구조

코디세이 입학연수(AI 네이티브) 미션 결과물을 미션별 폴더로 나눠 둡니다.

```
1주차/                         AI와 함께 만들기 연습 (영화 티어리스트)
  미션1_기획과HTML첫버전/
2주차/                         AI로 나만의 HTML 페이지 만들기
```

### 미션 폴더 규칙

- 폴더 이름: `N주차/미션번호_짧은제목/` (예: `1주차/미션2_오류재현과수정/`)
- 미션 폴더 안에는 그 미션의 제출 파일을 모두 모읍니다: 기획서, HTML, `미션N_기록.md`, 코랩세션리포트
- `캡처/`: 직접 찍은 화면 캡처. 파일 이름에 무엇을 보여 주는지 적습니다 (예: `A_보관함카드_A칸이동_1107-172903.png`)
- `대화기록/`: AI와 나눈 대화 원문
- `실행검증/`: 완성 기준별 실행 결과 표(README.md)와 단계별 캡처·로그
- 앞 미션 결과물을 이어서 쓸 때는 다음 미션 폴더로 복사한 뒤 거기서 고칩니다. 원본은 앞 미션 폴더에 그대로 남겨 비교할 수 있게 합니다.
