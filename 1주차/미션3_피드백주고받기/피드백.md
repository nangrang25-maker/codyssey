# 민수 님께 보내는 피드백

잘된 점: 카드를 누르고 등급 글자를 누르는 방법이 편했어요. 창을 작게 줄여도 카드를 한 번 누르고 휠로 올려 S를 누르면 바로 옮겨졌어요. '처음으로'도 직접 추가한 영화까지 지우고 처음 8편만 미분류로 돌려놔서 기획서대로 잘 동작했어요. 위에 '8편 중 3편 나눔'처럼 진행 상황이 보이는 것도 좋았어요.

고치면 좋을 점

1. 본 것: 웨일에서 창 폭을 좁게 줄였더니 오른쪽이 잘려 '추가'·'처음으로' 버튼과 카드 일부가 보이지 않았고, 가로 스크롤바도 생기지 않아 잘린 부분을 볼 방법이 없었어요.
   기준: 기획서의 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다'
   제안: 좁은 화면에서는 버튼과 카드가 화면 폭에 맞춰 줄어들거나 아래 줄로 내려가면 좋겠어요. 휴대폰으로 쓰는 친구들도 같은 문제를 겪을 것 같아요.

2. 본 것: 영화 몇 편을 S·A·B·C로 옮긴 뒤 탭을 닫고 같은 파일을 다시 열었더니 8편이 모두 미분류로 돌아갔어요.
   기준: 기획서의 '같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다'
   제안: 옮기거나 추가할 때마다 배치가 브라우저에 저장돼서, 다시 열어도 직접 추가한 영화와 등급이 그대로 남으면 좋겠어요.

3. 본 것: 창 높이를 줄인 상태에서 맨 아래 미분류 카드를 S칸까지 끌어 봤더니, 끄는 동안 마우스 휠이 먹지 않아 카드를 화면 위 끝에 잘 맞춰야만 화면이 올라갔어요.
   기준: 기획서의 '카드를 끌어 놓으면 해당 칸으로 옮겨집니다'
   제안: 미분류 목록이 등급 칸 위나 옆에 있으면 끄는 거리가 짧아질 것 같아요. 누르고 등급을 누르는 방법은 편하니, 안내 문구에서 이 방법을 더 눈에 띄게 알려 줘도 좋겠어요.
