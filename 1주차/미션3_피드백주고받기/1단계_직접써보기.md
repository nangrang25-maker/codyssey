# 1단계: 받은 피드백을 열기 전에 직접 써 보기

- 날짜: 2026-11-11
- 환경: Windows, 네이버 웨일 브라우저, 파일을 더블클릭해 `file:///` 로 엶
- 방법: `민수_기획서.md`의 완성 기준을 하나씩 직접 해 보고, 한 행동과 실제 결과를 적음. `받은_피드백.md`는 이 단계를 마친 뒤에 열었음.

| # | 완성 기준 | 한 행동 → 실제 결과 | 결과 | 캡처 |
|---|---|---|---|---|
| 1 | 영화가 한 칸에만 있고, 옮긴 칸에 남는다 | 8편을 S·A·B·C에 2편씩 옮김 → 카드가 옮긴 칸에만 있고 '8편 중 8편 나눔'이 됨 | 통과 | [01](캡처/01_처음_연_화면_8편미분류.png), [02](캡처/02_8편_SABC로_옮김.png) |
| 2 | 제목을 입력하면 새 카드가 생긴다 | '은교'를 입력하고 추가 → 미분류에 카드가 생기고 '9편 중 8편'이 됨. S칸으로도 옮겨짐 | 통과 | [03](캡처/03_제목추가_은교_카드생김.png), [04](캡처/04_은교_S칸으로_옮김.png) |
| 3 | 같은 파일을 다시 열어도 영화와 등급이 남는다 | 옮긴 뒤 탭을 닫고 같은 파일을 다시 엶 → 8편이 모두 미분류로 돌아감. 저장되지 않음 | **실패** | [07](캡처/07_탭닫고_다시열기_8편모두미분류.png) |
| 4 | 화면 폭이 좁아져도 오른쪽이 잘리지 않는다 | 창 폭을 좁게 줄임 → 오른쪽이 잘리고 가로 스크롤바가 나타나지 않아 잘린 부분을 볼 수 없음 | **실패** | [06](캡처/06_창폭_좁게_줄임.png) |
| 5 | '처음으로'를 누르면 처음 영화 8개가 모두 미분류로 돌아간다 | 은교를 S에 둔 상태에서 '처음으로' → '8편 중 0편', 처음 8편만 미분류에 남음 | 통과 | [05](캡처/05_처음으로_누른_뒤.png) |
| 6 | 외부 파일이나 로그인 없이 HTML 한 장으로 열린다 | 파일을 더블클릭해 엶 → 로그인이나 다른 파일 없이 열림 | 통과 | - |
