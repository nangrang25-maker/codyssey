# 미션 2 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: Gemini 3 Flash (코디세이 학습 네이토) / [05_AI에게_원인질문_Gemini3Flash.png](캡처/05_AI에게_원인질문_Gemini3Flash.png), [07_이문제만_고쳐줘_요청.png](캡처/07_이문제만_고쳐줘_요청.png)
- 좁혀서 적은 한 문장: **제목에 띄어쓰기가 있는 영화만, 누르기와 끌어 놓기 둘 다, 다시 해도 매번 안 옮겨진다. 띄어쓰기가 없으면 긴 제목도 옮겨진다.**
- 좁히려고 해 본 것과 결과:
  1. '처음으로'를 누르고 영화 8개를 하나도 빼지 않고 눌러서 옮겨 봄 → 기생충·인터스텔라·라라랜드·범죄도시·타이타닉은 옮겨지고, 센과 치히로의 행방불명·어벤져스: 엔드게임·토이 스토리 3개는 안 옮겨짐 ([02](캡처/02_영화8개_옮겨보기_결과_3개남음.png))
  2. '처음으로' 후 같은 3개를 다시 옮겨 봄 → 매번 안 옮겨짐
  3. 누르기 대신 끌어 놓기로도 해 봄 → '토이 스토리'를 S칸에 끌어 놓으면 S칸에 초록 테두리(끌어 온 표시)만 생기고 카드는 미분류에 그대로, 안내 문구도 '옮겼어요'로 바뀌지 않음 ([03](캡처/03_끌어놓기_초록테두리만_안옮겨짐.png))
  4. 되는 5개와 안 되는 3개 비교 → 짐작 두 가지: "5글자 이상" 또는 "띄어쓰기가 있음"
  5. 짐작 확인용 제목 추가: 띄어쓰기 없는 긴 제목 '님아그강을건너지마오'는 옮겨지고, 짧지만 띄어쓰기가 있는 '은 교'는 안 옮겨짐 → 길이가 아니라 띄어쓰기가 원인 ([04](캡처/04_짐작확인용_제목추가_긴제목은옮겨짐_은교는안됨.png))
- AI가 말한 원인과, 그 설명을 직접 확인한 결과:
  - AI가 말한 원인: 카드에 붙는 이름표(`data-id`)에 따옴표가 빠져 있어서, 띄어쓰기가 있으면 이름표가 띄어쓰기 앞에서 잘린다. 그래서 '토이 스토리'를 옮기려 하면 '토이'라는 영화를 찾게 되어 동작하지 않는다.
  - 직접 확인: AI가 알려 준 대로 카드에 오른쪽 클릭 → 검사를 해 보니, '토이 스토리'는 `data-id="토이"` 뒤에 `스토리`가 따로 떨어져 있었고 '센과 치히로', '어벤져스: 엔드게임', '은 교'도 첫 단어에서 잘려 있었다. '기생충'은 `data-id="기생충"`으로 온전했다. **설명이 내가 본 것과 맞았다.** ([06a](캡처/06a_검사_토이스토리_data-id_잘림.png), [06b](캡처/06b_검사_기생충_data-id_정상.png))

## 확인 자료 (글로 옮겨 둔 것)

- 시험 환경: Windows, Chrome 계열 브라우저(개발자 도구 버전 150), 파일을 직접 열어서(`file://`) 시험
- AI 답변 핵심 문장 (Gemini 3 Flash, [05](캡처/05_AI에게_원인질문_Gemini3Flash.png)): "HTML에서 속성값에 띄어쓰기가 있으면, 컴퓨터는 띄어쓰기 앞부분까지만 값으로 인식합니다." / "띄어쓰기가 있는 제목은 이름표(data-id)가 중간에 잘려서 컴퓨터가 어떤 영화인지 찾지 못하게 된 것입니다."
- 검사 도구에서 본 내용 ([06a](캡처/06a_검사_토이스토리_data-id_잘림.png), [06b](캡처/06b_검사_기생충_data-id_정상.png)):

```html
<!-- 안 되는 영화: 이름표가 '토이'에서 끊기고 '스토리'는 따로 떨어짐 -->
<button type="button" class="card" draggable="true" data-id="토이" 스토리 ...>토이 스토리</button>
<!-- 되는 영화: 이름표가 제목 전체 -->
<button type="button" class="card" draggable="true" data-id="기생충" ...>기생충</button>
```

- 원본 대비 바뀐 곳 (`영화_수정전.html` → `영화_수정1.html`, 카드를 만드는 부분 한 줄):

```diff
-      template.innerHTML = '<button type="button" class="card" draggable="true" data-id=' + item.id + '>' + item.title + '</button>';
+      // [수정] data-id 속성값에 따옴표(")를 추가하여 띄어쓰기가 포함된 제목도 온전히 인식되게 함
+      template.innerHTML = '<button type="button" class="card" draggable="true" data-id="' + item.id + '">' + item.title + '</button>';
```

- 원본 보관 방식: `영화_수정전.html`은 처음 받은 그대로 GitHub에 커밋해 두었고(커밋 `58f812e`), 이후 한 번도 고치지 않았다.

- 참고: 처음 받은 코드를 저장할 때 파일이 비어 있어(0바이트) 브라우저에서 열리지 않았다. 코드 문제가 아니라 저장 실수였고, 코드를 다시 붙여 넣어 저장하니 잘 열렸다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 띄어쓰기가 있는 제목은 추가하지 못하게 막는 것과, 띄어쓰기가 있어도 옮겨지게 고치는 것 중 무엇이 나은지. 나는 기획서에 "새로 추가한 영화 모두 옮길 수 있다"고 되어 있어서 고치는 쪽을 골랐는데, 다른 사람은 어떻게 판단했는지 궁금하다.
